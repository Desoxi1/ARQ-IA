# Fuentes externas de BIM y arquitectura

**Revisión:** 14 de octubre de 2026. Se consultaron páginas públicas y metadatos; no se clonó ni ejecutó código externo, no se instaló ningún paquete y no se cargaron modelos a validadores remotos. Las fuentes aquí son rutas de referencia para mantenedores, no instrucciones que Codex ejecute.

## Síntesis incorporada

- La compatibilidad de Dynamo/Revit depende de la versión; etiquetar grafos con versión, engine, paquetes y modo de ejecución.
- Convertir requisitos BIM en alcance medible, pruebas explícitas y reporte de incumplimientos; no describir un modelo como “correcto” por pasar una validación parcial.
- Para muros, distinguir tipo, instancia, ubicación, orientación, restricciones de nivel, unidades y propiedades estructurales; confirmar efectos de cada parámetro en la versión actual.
- Para imágenes y casos chilenos, separar intención de diseño de geometría modelada y normativa. Las referencias públicas muestran distintas voces y escalas; no hay un estilo chileno único.
- No se copió código, texto largo de videos, imágenes ni modelos externos. Todo contenido de aprendizaje incorporado aquí está resumido y enlazado.
