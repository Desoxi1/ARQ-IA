El 24-09-2026, las consultas de vista activa y selección respondieron en una sesión interactiva; no se modificó el modelo y se omitieron sus identificadores de esta copia pública. La configuración de Codex incluye herramientas de lectura y una lista acotada de creación/edición tipadas con aprobación por llamada. El perfil no habilita ejecución arbitraria C#, Python, ToolBaker ni Dynamo automático. Falta validar la integración MCP desde Codex con la carpeta como proyecto confiable.
